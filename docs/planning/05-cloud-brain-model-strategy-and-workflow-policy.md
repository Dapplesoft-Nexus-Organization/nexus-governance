## ১. নির্বাহী সারসংক্ষেপ ও অবকাঠামোগত ভিত্তি (Core Infrastructure Reality)

Dapplesoft Nexus-এর মূল ডিজাইন ফিলোসফি হলো: **"স্মার্ট রিসোর্স অপ্টিমাইজেশন ও জিরো-সার্ভার-ওভারলোড"**।

* **ক্লাউড-ফার্স্ট প্রাইমারি ব্রেন (Cloud-Only Brain):**  
  Nexus-এর **Primary Brain কখনোই লোকাল পিসি বা নিজস্ব VPS-এ রান হবে না**—এটি সর্বদা সম্পূর্ণ ক্লাউডে (Serverless / Hosted API) চলবে।
* **ন্যূনতম ৮ GB RAM VPS-এর সুরক্ষা:**  
  আমাদের মূল সার্ভার বা VPS-এ কোনো ভারী লোকাল LLM (যেমন 70B বা 32B মডেল) চালানো হবে না, যাতে মেমোরি ক্র্যাশ বা CPU স্যাচুরেশন না ঘটে।  
  **৮ GB RAM সম্পূর্ণ সংরক্ষিত থাকবে:**
  1. মূল অ্যাপ্লিকেশন (.NET Core Minimal API / Nexus Core Engine)
  2. PostgreSQL 16+ (উইথ `pgvector` এক্সটেনশন)
  3. Nexus Workflow Engine ও Task Workers
  4. Caddy / YARP রিভার্স প্রক্সি ও MinIO S3 ফাইল স্টোরেজ।
* **কাজের প্রয়োজনভিত্তিক ডিস্ট্রিবিউশন:**  
  কাজের ধরন ও খরচের ভারসাম্য অনুযায়ী ক্লাউড AI এবং লোকাল ডিটারমিনিস্টিক টুলের মধ্যে নিখুঁত শ্রম বণ্টন করা হবে।

## ২. চূড়ান্ত মডেল ও দায়িত্ব বণ্টন ম্যাট্রিক্স (Model & Task Allocation Matrix)

| কাজের ক্ষেত্র | নিয়োজিত মডেল বা প্রযুক্তি | ব্যবহারের সুনির্দিষ্ট কারণ ও সুবিধা |
|---|---|---|
| **প্রধান Brain / Workflow Planner** | **GLM-4.7-Flash**<br>*(Cloudflare Workers AI)* | সমস্যা বিশ্লেষণ, ধারাবাহিক পরিকল্পনা তৈরি, সঠিক টুল নির্বাচন ও মাল্টি-স্টেপ Tool Calling। সম্পূর্ণ ক্লাউডে চলায় VPS-এর RAM/CPU-তে শূন্য চাপ। Cloudflare Workers AI ফ্রি কোটায় পরিচালনাযোগ্য। |
| **বিকল্প / সেকেন্ডারি Brain** | **Qwen3 30B A3B**<br>*(Cloudflare Workers AI)* | ডিপ রিজনিং, সুনির্দিষ্ট নির্দেশনা পালন (Instruction Following) ও ফাংশন কলিং। প্রধান মডেলের প্ল্যান তুলনা ও ফেইলওভার বিকল্প হিসেবে কার্যকর। |
| **উন্নত / জটিল বিশ্লেষণ** | **হোস্টেড কমার্শিয়াল API**<br>*(যেমন OpenAI GPT মডেল)* | অত্যন্ত জটিল আর্কিটেকচারাল সিদ্ধান্ত, গভীর নিরাপত্তা যাচাই বা জটিল ব্যবসায়িক বিশ্লেষণ; খরচ ও ফলাফলের সুস্পষ্ট জাস্টিফিকেশন সাপেক্ষে। |
| **সহজ কাজের শ্রেণিবিন্যাস** | **Granite 4.0 H Micro** বা **Llama 3.2 3B**<br>*(Cloudflare Workers AI)* | প্রাথমিক টাস্ক ইনটেক (S0/S1), সাধারণ সারাংশ ও হালকা তথ্য বাছাইয়ের জন্য আল্ট্রা-ফাস্ট ও কম খরচের বিকল্প। |
| **কোডিং ও সফটওয়্যার পরিবর্তন** | **Qwen Coder** / অনুমোদিত কোডিং AI | সোর্স কোড লেখা, টেস্ট কেস জেনারেশন, বাগ ফিক্স ও রিপোজিটরি বিশ্লেষণ। লোকাল টুলে দ্রুত ও নিরাপদে করা সম্ভব কি না প্ল্যানার তা যাচাই করবে। |
| **সার্ভার ও ডেটাবেস পরিচালনা** | **নিজস্ব Workflow Engine** + SSH / PowerShell / Bash + PostgreSQL CLI | CPU, RAM, সার্ভিস ও ডেটাবেস হেলথ চেক করতে কোনো AI দরকার নেই। সাধারণ ডিটারমিনিস্টিক স্ক্রিপ্ট চলবে; AI কেবল অপ্রত্যাশিত ত্রুটি বিশ্লেষণে ডাকা হবে। |
| **ওয়েবসাইট, UI/UX ও ব্রাউজার পরীক্ষা** | **Playwright Runner** + হোস্টেড Vision/Reasoning মডেল (প্রয়োজনে) | ব্রাউজার রেন্ডারিং ও DOM টেস্ট লোকাল প্লে-রাইট টুল দিয়ে হবে। স্ক্রিনশট বা জটিল ভিজ্যুয়াল বাগ শনাক্ত করতে কেবল হোস্টেড ভিশন মডেল কাজ করবে। |
| **SEO, Analytics ও সার্চ কনসোল** | **অফিসিয়াল API** + নিজস্ব কোড + GLM/Qwen | Google Search Console ও Analytics API থেকে বাস্তব ডাটা সংগ্রহ; AI কেবল ফলাফল ব্যাখ্যা করে পরবর্তী স্ট্র্যাটেজি প্রস্তাব করবে। |
| **কীওয়ার্ড রিসার্চ ও মার্কেটিং** | **হোস্টেড Brain** + Web Search / Crawl API | রিয়েল-টাইম সার্চ ডাটা ও প্রতিদ্বন্দী বিশ্লেষণ করে ক্যাম্পেইন প্ল্যান প্রস্তুত। |
| **কনটেন্ট লেখা ও প্রকাশ** | **GLM / Qwen** + প্ল্যাটফর্ম পাবলিশিং API | কনটেন্ট তৈরি করবে AI; কিন্তু তা সোশ্যাল বা ব্লগে স্বয়ংক্রিয়ভাবে প্রকাশ করবে অনুমোদিত ডিটারমিনিস্টিক Workflow Engine। |
| **RAG ও পুরোনো জ্ঞান অনুসন্ধান** | **PostgreSQL + pgvector** + Embedding Model | অতীতের টিকিট, সফল কাজের সমাধান, বিজনেস পলিসি ও ডক্স ভেক্টর সার্চ করে Brain-এর প্রম্পটে প্রাসঙ্গিক কনটেক্সট সরবরাহ করা। |
| **কাজের ফলাফল যাচাই (Evals)** | **ডিটারমিনিস্টিক স্ক্রিপ্ট** + Brain এনালাইসিস | ইউনিট টেস্ট ও এক্সিট কোড ফলাফল যাচাই করবে; জটিল লজিক্যাল ব্যর্থতার কারণ উদ্ঘাটনে Brain পর্যালোচনা করবে। |

## ৩. ফ্রি বনাম পেইড রিসোর্স ব্যবহারের ভারসাম্য নীতি (Resource Economics)

1. **ফ্রি কোটা ফার্স্ট (Zero-Cost Priority):**
   * **Cloudflare Workers AI (GLM-4.7-Flash ও Qwen3 30B):** প্রতিদিনের ফ্রি কোটার মধ্যে প্রধান ব্রেন ও প্ল্যানিং চালানো হবে।
   * **Granite / Llama Micro:** ছোট টাস্ক ক্লাসিফিকেশনে ফ্রি কোটায় অগ্রাধিকার পাবে।
   * **PostgreSQL, PowerShell, Bash, Playwright:** লোকাল ও সার্ভার ইউটিলিটিগুলোর কোনো AI API খরচ নেই।
2. **পেইড বিলিং প্রটোকল (Paid API Governance):**
   * অতিরিক্ত ট্রাফিকে Cloudflare পেইড রেট বা বাণিজ্যিক GPT API ব্যবহারের প্রয়োজন হলে Brain অ্যাডমিনকে খরচের আনুমানিক হিসাব (Estimated Cost) প্রদর্শন করবে এবং পূর্বানুমোদন চাইবে।

## ৪. Nexus-এর বাধ্যতামূলক Workflow নীতি (Mandatory Execution Rules)

প্রতিটি নতুন কাজ, প্রম্পট বা ব্যবহারকারীর নির্দেশের ক্ষেত্রে সিস্টেম কঠোরভাবে নিচের ৬টি ধাপ মেনে চলবে:

└───────────────────────────────────┬────────────────────────────────────┘
                                    │ Context Bundle

│    GLM-4.7-Flash দ্বারা ৮ GB VPS মেমোরি ও খরচের হিসাব সহ প্ল্যান জেনারেশন   │
└───────────────────────────────────┬────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────┐

│      Nexus Workflow Engine কাজ সম্পন্ন করে — অপ্রয়োজনে AI কল সম্পূর্ণ নিষিদ্ধ    │

### প্রধান ৫টি নিয়মাবলী (Strict Directives):
1. **প্রথমে RAG:** নতুন কোনো সমস্যা সমাধানের আগে ব্রেন PostgreSQL-এর মেমোরি থেকে সমাধান খুঁজবে।
2. **লোকাল টুল প্রাধান্য:** যা শেল স্ক্রিপ্ট, এসকিউএল বা প্লে-রাইট দিয়ে সরাসরি সমাধান সম্ভব, তার জন্য অতিরিক্ত এলএলএম কল করা যাবে না।
3. **অপ্রয়োজনে Brain কল নিষিদ্ধ:** একবার প্ল্যান অ্যাপ্রুভ হয়ে গেলে Nexus Workflow Engine নিজস্ব পাইপলাইনে ধাপে ধাপে কাজ করবে। শুধুমাত্র কন্ডিশনাল ব্রাঞ্চিং, এক্সেপশন বা জটিল ভ্যালিডেশনের সময় Brain-কে আবার জাগানো হবে।
4. **সার্ভার মেমোরি পাহারা:** যেকোনো কাজের মেমোরি রিকোয়ারমেন্ট যেন কখনোই হোস্ট VPS-এর ৮ GB সীমাকে আঘাত না করে।
5. **সম্পূর্ণ হিসাব নিকাশ:** প্রতি টাস্কে ব্যবহৃত টোকেন, ক্লাউড প্রোভাইডার, ল্যাটেন্সি ও খরচ ডেটাবেসে স্থায়ীভাবে লিপিবদ্ধ থাকতে হবে।
